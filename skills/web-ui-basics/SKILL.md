# 업무용 웹 화면 기본

화려함보다 요구를 정확히 충족하는 화면이 목표다. 요구에 없는 페이지·차트·애니메이션은 추가하지 않는다.

1. **화면 상태를 빠짐없이 만든다.** 정상 / 불러오는 중 / 데이터 없음 / 서버 오류 / 입력 오류. 빈 값과 예외에서 숨은 조건이 자주 드러난다.
2. **표시가 데이터와 일치해야 한다.**
   - 요약 숫자와 상세 합계가 같아야 한다. 계산은 코드에서 하고 화면에서 따로 다시 계산하지 않는다.
   - 단위·날짜·시간대 기준을 화면에 밝힌다. 업무 문서의 용어를 그대로 쓴다.
   - 알 수 없는 값은 지어내지 않고 "미확인"이나 빈 표시로 둔다.
3. **핵심 정보와 핵심 동작을 먼저 둔다.** 클릭을 줄이고, 필터·검색이 무엇을 바꾸는지 보이게 한다.
4. **기본을 지킨다.** 입력마다 `label`, 키보드 포커스 표시, 충분한 글자 대비, 좁은 화면에서도 내용이 보이게.
5. **외부에 의존하지 않는다.** CDN·웹폰트·외부 이미지·외부 API를 쓰지 않고 시스템 서체와 로컬 파일만 쓴다. 미리보기에서 외부 접속이 되는지는 확인된 바가 없다.
6. **개인정보를 요구 없이 보여 주지 않는다.** 이메일·전화번호 등은 과제가 요구할 때만 쓴다.
7. **색·간격은 소수의 변수로 일관되게 한다.** 장식은 요구에 도움이 될 때만 넣는다.
8. **화면 확인표를 만들어 준다.** `입력/동작 → 기대 결과` 표로 정리해 응시자가 제공된 미리보기에서 직접 확인하게 한다. 에이전트는 브라우저를 조작하거나 화면을 캡처하지 않는다. 서버 응답과 API는 `curl`이나 테스트로 확인한다.

산출물: 화면 코드와 화면 확인표. 응시자가 확인하지 않은 동작은 "미검증"으로 남긴다.

하지 않을 것: 요구에 없는 장식·페이지 추가, 외부 CDN 의존, 화면에서 값을 따로 계산해 데이터와 어긋나기.
