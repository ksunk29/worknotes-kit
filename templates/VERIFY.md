# VERIFY — 근거표

> 별도 문서를 늘리지 않는다. 과제가 요구한 제출 문서가 있으면 이 표를 **그 문서에 그대로 옮겨** 쓴다.
> 상태: **확인함**(실제로 실행·대조해 맞음) / **미검증**(구현했지만 확인하지 못함) / **실패**(확인했더니 틀림) / **미확인**(자료나 담당자 답이 없어 알 수 없음)

## 요구·주장별 근거
| 요구·주장 | 출처 | 구현·계산 위치 | 검증 결과 | 상태 |
|---|---|---|---|---|
| 예: 불량 행은 격리하고 계속 처리 | 담당자 답변 Q5 | `src/run.js` `parseRow()`, 커밋 `a1b2c3d` | `node src/run.js ...` 종료 코드 0, `rejected.jsonl` 12줄(기대 12) | 확인함 |
| | | | | |

- 출처: 과제 안내·문서(파일·쪽·행)나 담당자 답변 번호. 자료에 없으면 "추정"이라고 쓰고 상태는 미확인.
- 구현·계산 위치: 파일·함수·커밋, 계산이면 사용한 명령이나 식.
- 검증 결과: 확인한 명령·입력과 실제 결과(기대와 비교).
